Support & Documentation

Everything you need to know about setting up, configuring, and troubleshooting Ivors on macOS Sonoma & Sequoia.

⚡ Quick Install & Updates

How do I install or update via Homebrew?
To install Ivors with Homebrew Cask:
brew tap mayank013p/ivors https://github.com/mayank013p/ivors && brew install --cask ivors
To update to the latest release:
brew upgrade --cask ivors
How do I install via direct 1-line Terminal command?
Run this command in Terminal to download, strip quarantine attributes, and launch Ivors instantly:
curl -fsSL https://raw.githubusercontent.com/mayank013p/ivors/main/install.sh | bash

🛡️ macOS Permissions & Privacy

Why does Ivors request macOS permissions?
Ivors uses native macOS APIs to power its widgets:

• Bluetooth: To read battery percentage and connection status for AirPods and wireless gear.
• Automation / Apple Events: To control Spotify and Apple Music playback from the notch.
• Microphone: To display the live privacy indicator and 1-click mute widget (Ivors never records or transmits audio).
• Accessibility: To support the global shortcut (⌥ Option + Space) and trackpad gestures.
How to grant or reset permissions?
Open System Settings → Privacy & Security, and verify that Ivors is checked under Accessibility, Bluetooth, and Automation.

🎮 Controls & Keyboard Shortcuts

What are the default shortcuts?
• ⌥ Option + Space : Toggle Dynamic Island expansion
• Hover on Notch : Smoothly expands the island HUD
• Two-Finger Horizontal Swipe : Switch between widgets
• Drag & Drop File : Drop any file onto the notch to stash it
• ESC : Collapse expanded island

🗑️ Clean Uninstallation

How do I cleanly uninstall Ivors?
Method 1: In-App Clean Uninstaller
Click the ✦ sparkles icon in your Menu Bar → Preferences → About tab → Click "Uninstall Ivors...".

Method 2: Homebrew
brew uninstall --cask ivors
Method 3: Terminal Command
curl -fsSL https://raw.githubusercontent.com/mayank013p/ivors/main/scripts/uninstall.sh | bash
